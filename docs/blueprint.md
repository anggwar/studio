# **App Name**: Global New Year Countdown

## Core Features:

- Countdown Display: Show the countdown to the New Year, customizable by font and color.
- Time Zone Selection: Allow users to add and switch between multiple global locations to track New Year's arrival.
- Custom Wallpaper: Allow users to upload custom PNG/JPG wallpapers to personalize the countdown display.

## Style Guidelines:

- Primary color: Deep midnight blue (#191970) to evoke a festive night sky.
- Background color: Soft desaturated midnight blue (#262647) for a calming base.
- Accent color: Rich gold (#D4A274) for countdown numbers and highlights, adding a touch of elegance.
- Font Selection: Allow users to choose font for the text. Note: currently only Google Fonts are supported.
- Use simple, elegant icons to represent different locations and settings.
- Ensure a clean and intuitive layout, with the countdown timer prominently displayed.
- Incorporate subtle animations such as twinkling stars or sparkling effects as the countdown reaches zero.
